# Glossary

Domain terms used throughout the CVFairy knowledge base.

## Resume Terms

- **ATS (Applicant Tracking System)** — Software used by employers to filter, parse, and rank resumes automatically. Examples: Workday, Greenhouse, Lever, iCIMS.
- **ATS-friendly** — A resume format that parses correctly through ATS software (clean structure, selectable text, standard section headings).
- **Bullet point** — A single achievement or responsibility line under a job entry. Best format: action verb + task + result + metric.
- **Job tailoring** — Rewriting a resume to match a specific job description's keywords and requirements.
- **JD (Job Description)** — The posting for a job role, containing requirements, responsibilities, and qualifications.
- **Keyword gap** — Skills or terms present in a JD but missing from the resume.
- **Parsed view** — How an ATS extracts and displays resume data (structured text without formatting).

## Resume Sections

- **Personal Info** — Name, email, phone, location, links. Always at the top.
- **Summary / Objective** — 2-4 sentence overview of qualifications and goals.
- **Experience** — Work history entries with title, company, dates, and bullet points.
- **Education** — Degrees, schools, dates, and optional GPA/honors.
- **Skills** — Technical and soft skills, optionally grouped by category.
- **Certifications** — Professional certifications with issuing body and date.
- **Projects** — Notable projects with description, tech stack, and links.
- **Languages** — Spoken/written languages with proficiency level.
- **Awards** — Honors, awards, and recognitions.
- **Volunteer** — Volunteer experience (similar format to Experience).

## Technical Terms

- **Local-first** — Architecture where data is stored on the user's device by default, with optional cloud sync.
- **IndexedDB** — Browser API for storing significant amounts of structured data client-side.
- **Edge runtime** — Server-side JavaScript execution environment at CDN edge nodes (Cloudflare Workers). Limited Node.js API support.
- **D1** — Cloudflare's serverless SQLite database.
- **R2** — Cloudflare's S3-compatible object storage.
- **KV** — Cloudflare's key-value store for low-latency reads.
- **Workers AI** — Cloudflare's inference API for running AI models at the edge.

## Product Terms

- **Free tier** — No payment required. 3 templates, PDF export, 5 AI requests/day.
- **Pro tier** — Paid subscription. All templates, all exports, unlimited AI, ATS checker.
- **Lifetime** — One-time payment for permanent Pro access.
- **BYOK (Bring Your Own Key)** — Users provide their own AI API keys for higher-quality models.
