# REQ-011: Internationalization

**Status:** todo
**Phase:** 3 (Full Platform)
**Priority:** p2-medium
**Depends on:** [[REQ-001-resume-editor]]
**Blocks:** none

## Description

Multi-language support for the CVFairy UI and resume content. Launch with 5 languages, add more over time. Users can write resumes in any language; the UI language is separate from resume content language.

## Acceptance Criteria

1. UI available in: English, Spanish, French, German, Portuguese
2. Language switcher in header and settings
3. Locale-aware date formatting in resume content
4. URL-based locale routing (`/en/editor`, `/es/editor`)
5. SEO: hreflang tags, localized meta descriptions
6. Resume content is language-agnostic (users type in any language)
7. AI features work in the user's chosen language
